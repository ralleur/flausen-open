# Eigene Farbthemes

## Graphite Blue

Dunkles Theme auf Basis von Graphite Coral mit der Akzentfarbe `#245FC0`.
Graphitflächen und semantische Statusfarben bleiben erhalten. Die Primärabstufungen
sind blau; Text auf der Akzentfläche ist weiß (Kontrast 6,05:1).

Palette: `graphite-blue/default/dark.txt`.
Installiert unter `~/.local/lib/caelestia/schemes/graphite-blue/default/dark.txt`
und im Caelestia-Quellbaum unter `~/caelestia-kde/src/schemes/graphite-blue/`.

Aktivieren:

```sh
caelestia scheme set -n graphite-blue -f default -m dark
```

Vorheriges Theme wiederherstellen:

```sh
caelestia scheme set -n graphite-coral -f default -m dark
```
